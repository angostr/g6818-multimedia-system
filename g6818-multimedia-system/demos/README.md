# 练习代码

这些文件是学习过程中逐步编写的独立练习程序，每个文件测试一个独立的硬件功能模块。

| 文件 | 功能 |
|------|------|
| `test.c` | 基础 C 语法测试 |
| `2.cpp` | C++ 练习 |
| `circle_and_juxing.c` | LCD 画圆 / 画矩形 |
| `disbmp.c` | BMP 图片解码与显示 |
| `displaycolor.c` | LCD 颜色填充 |
| `touch.c` | 触摸屏坐标读取 |
| `uart.c` | UART 串口 + GY39 传感器 |
| `uart1.c` | UART 基础通信 |

这些文件仅供参考学习，不构成主项目的一部分。
