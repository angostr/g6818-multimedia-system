

# mplayer

是一个开源的多媒体播放器 GNU通用公共许可证发布  可以供主流系统使用  linux和类unix  win  macos

有两种工作模式   一种普通模式   一种从模式
                

            
## 普通模式

    在开发板的终端上 输入

        ./mplayer1.4 音视频的文件名

            此时mplayer1.4 是一个可执行文件 类似a.out

       


        直接通过键盘来达到控制的效果

        ->   <- 电脑的方向键

        space  暂停/继续


    ./mplayer1.4  -zoom -x 800 -y 480 -geometry 0:0  -quiet      1.mp4
                        设置尺寸           设置位置     安静模式


## 从模式

    可以使用不仅仅从标准输入设备获取命令 从”管道“文件中获取命令
    管道是一个特殊的文件 存放在内核中  是进程间通信的方式之一
